## Scope and mode

Redesign the buildless review app (`src/client/`) in Operate mode and the static overview/docs site (`site/`) in Persuade and Read modes.

## Audience and job

Developers reviewing agent-generated changes locally must be able to orient to the comparison, read every relevant line, attach precise feedback, and close the review loop without losing context.

## Content and action

The app centers the file index, diff, comment threads, review status, and feedback handoff. The site proves the inspect-comment-return-refresh-resolve-approve loop with real Loupe content, then leads to installation or deeper documentation.

## Constraints

Preserve all current behavior, keyboard shortcuts, performance optimizations, buildless architecture, and contract types. Ship complete light and dark modes, accessible contrast and focus, reduced motion, and functional mobile navigation.

## Direction and memorable moment

Proof desk / redline galley. The memorable moment is placing an anchored proof mark on an exact changed line and seeing it become agent-ready feedback. The custom split-aperture mark, registration rules, restrained ink palette, and paper/charcoal surfaces span app and site.

## Unresolved

Refresh product screenshots and walkthrough media after the production UI is stable so the site does not preserve the discarded visual system.
